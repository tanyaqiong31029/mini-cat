导出

译文交付

Word 与 HTML 交付保留网页译文的加粗、斜体、下划线和上下标。TXT、CSV、XLSX 及翻译记忆导出仅保留文字。纯译文按原文段落自动重建。

审校与修订

修订痕迹在 Word 中以原生修订模式呈现（删除线/下划线 + 修订人署名），批注以 Word 批注呈现——可直接用审阅功能逐条处理。

翻译数据

导出的 TMX / TBX 可直接回流 porcelain-china-corpus 或导入 Trados / memoQ。CSV 为原始数据交换格式（无公式注入防护，用表格软件打开时注意以 = + - @ 开头的单元格）；在表格软件中查看请优先用 XLSX 版本（单元格为显式文本类型）。

导入修订（审校留痕）

选择文件后自动与当前项目句段匹配：识别修订 / 无变化 / 新增。

匹配键为中文原文。文本有变化的段落追加为新版本并保留旧版；未匹配的句对将作为新增段落导入。原文列不会被修改。

署名设置
